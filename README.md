# Arhaviora-frontend


## Premium Personalized Baby Ecommerce Platform

 Arhaviora is a premium ecommerce frontend experience designed for personalized baby essentials, newborn products, nursery accessories, and gifting.

The frontend is developed based on the approved Figma design system with a focus on:

- Premium UI experience
- Responsive design
- Scalable component architecture
- Ecommerce-ready functionality
- Personalization experience

---

# 🚀 Features

## Customer Experience

- Modern premium ecommerce interface
- Product browsing
- Category exploration
- Product search
- Product filtering
- Sorting
- Wishlist management
- Shopping cart
- Checkout flow
- Order confirmation


## Product Personalization

Users can customize products with:

- Baby name
- Font selection
- Thread color
- Gift message
- Live preview


## Ecommerce Modules

Implemented modules:

- Homepage
- Shop Page
- Product Details
- Cart
- Checkout
- Authentication
- User Profile
